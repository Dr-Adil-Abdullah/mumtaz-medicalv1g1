📋 GitHub Complete Guide

Preview → Approve → Merge — Step by Step for Beginners

1

🌐 PART 1: Preview the Website Live

Goal: See the website on your phone/computer BEFORE approving

Step 1.1 — Open this link in a new tab
🔗 https://dr-adil-abdullah.github.io/mumtaz-medicalv1g1/feature-about-v2/about.html

Copy this link and paste it in your browser (Chrome, Safari, etc.)

Step 1.2 — What you should see
✅ If it works: You see a dark-themed page with green colors, "About Mumtaz Medical" heading, stats, cards, team section, and a ☰ menu button on top-left.

❌ If you see old page or blank: Press Ctrl + Shift + R (or Cmd + Shift + R on Mac) to hard refresh.
Step 1.3 — Test it

📱 Open the same link on your phone too — it should look good
☰ Click the ☰ menu button on top-left — sidebar should slide in
📦 Click Inventory, Staff, Log in sidebar — it shows "coming soon" alert
← Click "Back to Home" at bottom — goes to home page

Step 1.4 — Decision time
✅
You LIKE it
Go to Part 2 (Approve)
❌
You DON'T like it
Tell me what to fix
2

👍 PART 2: Approve the Pull Request

Goal: Tell GitHub "I checked the code, it's good"

Step 2.1 — Open the PR page

Open this link in your browser:

🔗 github.com/.../pull/9
Step 2.2 — You will see this page
github.com/Dr-Adil-Abdullah/mumtaz-medicalv1g1/pull/9
feat: Complete redesign of About Us page #9 Open
💬 Conversation
📦 Commits
✅ Checks
📄 Files changed ← CLICK THIS!

Click the "Files changed" tab at the top

Step 2.3 — After clicking "Files changed"

You will see the code changes (green lines = new code). Now look at the TOP-RIGHT of the page for this button:

+ Review changes ← CLICK THIS!
Step 2.4 — A popup will appear

You will see 3 radio options. Select "Approve":

Leave a review
💬 Comment
❌ Request changes
✅ Approve ← SELECT THIS ONE!
(Optional) Write a comment...
Submit review ← CLICK THIS!
🎉 Done! You have approved the PR. Now go to Part 3 to merge it.
3

🔗 PART 3: Merge the Pull Request

Goal: Add the new code to the main website

Step 3.1 — Go back to "Conversation" tab
💬 Conversation ← CLICK THIS!
📦 Commits
✅ Checks
📄 Files changed
Step 3.2 — Scroll to the bottom of the page

You will see a big GREEN button:

🔀 Merge pull request ← CLICK THIS!
Step 3.3 — Confirm merge

After clicking, a new row appears. Click the second green button:

Merge method: Create a merge commit
✅ Confirm merge ← CLICK THIS!
🎉🎉 DONE! The code is now merged! Your main website is updated automatically.

After merge, you can check the live site at:
https://dr-adil-abdullah.github.io/mumtaz-medicalv1g1/main/about.html
